# 服务器使用与计划管理升级

## 用户与边界

单人项目负责人在中国办公，应用随后部署在美国的自有服务器和域名。继续使用 Django、SQLite、原生模板及本地静态资源。项目计划为主，同时支持今日、本周、下周工作安排。所有 AI 结果保持先审阅再入库。

## 本轮交付

1. 持久化解析队列与独立 worker。提交立即返回；刷新、关闭页面不取消任务；状态可查询，失败可重试；重复提交合并，崩溃任务可恢复，过期执行结果不得覆盖新尝试。SQLite 事务不跨网络等待。
2. 项目阶段：名称、状态、顺序、起止日期。任务可归属阶段，禁止跨项目关联。项目详情展示任务完成、延期和里程碑，提供按周时间线；没有日期的阶段明确提示待排期。
3. 工作计划：任务增加独立安排日期，和截止日期分别管理。今日、本周、下周、待安排快捷视图，按项目/负责人筛选；一键安排到今天、下一周或取消安排，原生表单也能使用。过去未完成的安排持续可见。
4. 里程碑和风险可人工维护，支持完成里程碑和关闭风险，所有写入校验项目归属。
5. 轻量界面：明亮办公室场景，浅灰绿色侧栏、紧凑数据行、统一工具栏、日期和状态层次。桌面导航固定位置，手机使用可展开导航；无外部字体/CDN。
6. 性能：常用列表分页，清除 N+1，解析与网页请求分离，静态文件压缩与指纹缓存。
7. 部署：本地 Compose 继续可运行，另提供独立服务器 Compose、Caddy HTTPS、持久卷、单 worker、在线 SQLite 备份、校验与恢复说明，固定中国业务时区。实际远程上线需明确服务器与域名，当前交付可部署配置。

## 验证

- 隔离数据库和模拟模型验证队列幂等、失败、过期执行、恢复，HTTP 不等待模型。
- 验证计划周期边界、逾期遗留、日期顺序、跨项目拒绝以及里程碑/风险状态。
- Python 与前端已有回归、迁移漂移、Compose 配置检查和容器健康。
- 真实浏览器桌面与 390px 验收；模拟后台解析完成及导航离开后恢复。
- 备份在临时数据库中验证完整性与恢复，不以测试数据覆盖用户数据。
