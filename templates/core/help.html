日常使用，五个步骤

  1. 会前安排

    在项目中设置阶段与截止日期，在工作计划中选择哪天推进。准备下次会议可沿用上次人员和未完成任务。

    打开工作计划 →
  2. 会中记录

    选择汇报人，逐项填写进展。新任务可选择所属阶段；缺少项目和人员可以原地新建。

    新建会议 →
  3. 会后核对

    确认“已暂存”再离开。结束后预览变更，最终确认才写入任务。过去会议只补充已有任务历史；未来会议不能提前确认进度。

    继续未完成会议 →
  4. 持续跟进

    工作台优先展示待确认、到期和风险。复制按负责人整理的跟进文案，发到钉钉。

    打开工作台 →
  5. 生成周报

    按业务日期选择报告范围。会议日期决定本次进展归属，实际录入时间仍保留。

    打开周报 →

部署与数据安全

有本地数据时，使用迁移手册，不要按全新安装先创建新库。代码、SQLite 数据卷和 env 分开保管。

升级需要可回退的镜像版本和匹配快照。不要删除数据卷，也不要在本地与服务器同时继续写两份数据。

遇到异常先保留输入

暂存失败时不要刷新，先重试或复制当前输入。手动会议还可下载当前输入用于人工核对；冲突 JSON 不是整站备份，也不支持直接导回。

解析排队较久先检查 worker；旧会议和当前任务冲突时先重审，不要重复调用模型。
